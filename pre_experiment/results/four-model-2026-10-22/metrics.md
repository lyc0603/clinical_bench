## Qualifications

- Initial-only and self-review share generation and are paired endpoints, not independent runs.
- Do not sum both endpoint cumulative costs as batch spending; count each generation once.
- Historical P21-feedback controls are nonconcurrent; descriptive comparisons only.
- Repair metrics are not applicable to initial-only. Missing scores are not zero findings.
- All failures remain in the planned denominator; no successful retry substitution.
- Historical conformance scores use current accepted fixed-artifact revalidation; original scores remain unchanged in source evidence. Other historical metrics retain their original run measurements.
- Metric 3 shows original and current validator status separately. A successful reassessment does not erase an original technical failure; elapsed time and cost refer to original model workflows and exclude post-hoc host revalidation.
- Auxiliary checks cover selected conditional derivations, not comprehensive clinical correctness. Planned-check coverage is not an adjudicated applicable-check denominator.
- API costs are telemetry estimates, not invoices. Token totals retain provider cache/reasoning buckets; cross-provider billing semantics are not independently reconciled.
- DeepSeek was added later: two independent generation sessions supply three endpoints. This is an exploratory extension, not a prespecified main-study model.
- DeepSeek telemetry costs use declared peak rates; actual off-peak billing may be lower. Readiness costs are excluded. The official model alias is mutable.
