# GPT-OSS-120B three-condition exploratory pilot

This separately frozen extension runs one independent workflow each for initial-only, self-review and P21 feedback through DeepInfra. It does not launch the formal main study. All three initial generations are independent; historical paired endpoints elsewhere in the repository have a different dependence structure.

Model and sampler are the qualified `deepinfra/openai/gpt-oss-120b`, temperature 1.0, medium reasoning, 131,072 context metadata and 16,384 maximum response tokens. There is no agent time cap. The title helper is disabled, web search and subagents remain denied, and the provider gateway allows only api.deepinfra.com. Local Docker execution, frozen inputs/prompts and the original host evaluator are reused. One repair follows generation for self-review and P21 feedback. The original main runner's partial-report feedback and unusable-report self-review fallback behavior are preserved; no additional initial-package or auxiliary-correctness gate is introduced.

The freeze binds the original base seal, P21 clean-cache manifest and qualification, adapter/runner code, the controller-provisioned ripgrep executable, passing nonclinical transport and two-turn smoke evidence exercising bash/glob/grep/read, sampler and seeded execution order. It verifies hashes before every independent workflow and after the batch. Failures are retained, no automatic retries occur, and uncertain failures stop scheduling. Reports retain all three planned endpoints and mark unavailable values rather than zero. Repair metrics are not applicable to initial-only.

Use `python -m gpt_oss_120b_experiment.run --help`. Both `freeze` and `run` require the same explicit base configuration, P21 qualification, readiness/transport directories, qualified `--ripgrep` executable, private lock/output paths and local environment file. Actual generation additionally requires `run --execute`. All raw sessions, clinical outputs, P21 reports, credentials and dictionaries remain private. Publish aggregate metrics and sanitized evidence only. A pre-amendment batch encountering an unqualified glob dependency is preserved privately and excluded as an environment qualification failure; it must not be represented as model capability evidence. Any future replacement requires documented adjudication and a fresh freeze/output directory.

One repetition per condition supports feasibility and descriptive observations, not significance tests or a causal model-size/feedback claim. Hosted open-weight inference is not private local deployment and does not pin server-side weights. P21 conformance and selected auxiliary checks do not establish comprehensive clinical derivation correctness. Cost telemetry is an estimate, not an invoice; report generation excludes qualification spending.
